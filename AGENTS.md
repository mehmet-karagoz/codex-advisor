## Adaptive Model Routing

Use the model-advisor skill when planning development work.

Evaluate task complexity before substantial execution.

Prefer:

- fast_worker for simple, isolated tasks.
- standard_worker for normal development tasks.
- deep_expert for complex, high-risk investigations.

Delegate only when it improves efficiency or quality.

Keep the main session model unchanged.

Do not ask the user to select a model for every task.
If a stronger model is needed and delegation is unavailable,
recommend the appropriate manual model switch.

For exceptionally difficult tasks, prefer supported
higher reasoning effort when available.
